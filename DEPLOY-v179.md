# One-Line v179 — Requested catalogue updates only

1. Run **`supabase/v179-multiple-prints-inch-labels-public-details.sql`** in the Supabase SQL Editor. Review the two existing Admin detail fields first: after running this migration their values are visible on active customer-facing item pages above item names. 3. Upload the full website folder to GitHub/Cloudflare Pages. Keep the security-hardening changes and instructions in `DEPLOY-v178-SECURITY.md`.
4. Verify an order with two print types, an order without printing, old single-type saved carts, all three default print sizes, visible item details on active Custom Catalogue and Ready Made items, and old sizes converted from cm to inches. Existing measurement values are internally still stored as cm for compatibility.
