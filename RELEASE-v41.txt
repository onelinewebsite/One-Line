One-Line v41 — server-authoritative account sync

- Cart is no longer saved/restored from device localStorage.
- Order history is no longer saved/restored from device localStorage.
- Customer profile is always reloaded from Supabase; local storage keeps only the session token/stable identifiers.
- Same verified phone reconnects to the existing account and saved name; returning users are not asked for their name again.
- Profile edits sync across logged-in devices.
- Cart add/update/remove operations are atomic on the server and merge safely between devices.
- Cart/version polling updates other devices in about 2.5 seconds while the site is visible.
- Same-browser tabs also trigger an immediate account refresh with BroadcastChannel.
- Orders are created from the canonical server cart, then the server cart is cleared for every connected device.
- Order status changes made by Admin are detected and reflected in customer My Orders.
- Admin/Management live account pages refresh every 5 seconds.
- Old v40 `cart_sync` snapshots are ignored so a stale cached tab cannot overwrite the v41 server cart.
- Customizer garment layout/positioning was not changed.
